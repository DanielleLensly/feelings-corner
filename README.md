# Calming Corner 🌸 • Responsive React Web App

A warm, gentle, interactive, and responsive web application crafted specifically for emotional co-regulation, somatic grounding, and mindful breathing for children and caregivers.

---

## 🚀 Quick Start

To run the application locally:

```bash
# 1. Start the Vite development server
npm run dev

# Or build and preview the production build:
npm run build
npm run preview
```

Then open `http://localhost:3000` (or the URL displayed in your terminal) in your browser.

---

## ✨ Features & Modules

1. **💖 How I Feel (Feelings Check-In)**
   - Interactive emotion selector matching the watercolor feeling faces (**Happy**, **Sad**, **Silly**, **Tired**, **Worried**, **Angry**, **Calm**, **Excited**).
   - Places the selected face directly into the "Today I feel..." frame with tailored coping suggestions and immediate action buttons.

2. **🐢 Breathe With Me (Interactive Breathing Guides)**
   - **Infinity Breathing (Turtle):** Real-time moving turtle guide navigating a figure-8 lemniscate track with visual and gentle audio cues for inhale and exhale.
   - **Square Breathing (Bunny):** 4-4-4-4 box breathing guide with expanding/contracting center visual and hop timer.

3. **🌿 Find Your Ground (5-4-3-2-1 Sensory Grounding)**
   - Step-by-step checklist guiding the child through 5 senses (See, Touch, Hear, Smell, Love).
   - Real-time progress bar, calming sounds, and rewarding confetti completion.

4. **🧰 My Calm Down Toolbox (Somatic Body Tools)**
   - **Smell & Blow:** Flower sniff and candle flame blowing interaction.
   - **Wall Push-Ups:** 5-second countdown strength exercise.
   - **Tight Squeeze:** Hold-to-hug squeeze meter for teddy bears or pillows.
   - **Sip of Water:** 3 slow cool sips tracker.

5. **💬 What Do I Need Right Now?**
   - Expressive choice cards: *A Big Hug*, *Quiet Time*, *Talk It Out*, and *Move My Body*.

6. **⭐ Emotional Regulation Badges**
   - Children unlock and celebrate digital stickers (*I Paused*, *I Took A Breath*, *I Am Safe*, *Brave Heart*, *Body Is Calm*, *I Talked About It*) with progress saved in `localStorage`.

7. **📖 Caregiver Guide ("Co-Regulation Begins with Your Calm")**
   - 3 foundational caregiver principles, comforting phrase suggestions, and calming corner room setup tips.

8. **🖼️ Printable Poster Kit Gallery**
   - High-resolution gallery and one-click print capability for all five original posters.

9. **🎶 Ambient & Audio Support**
   - Pure Web Audio API synthesized pink noise ocean/rain hum and gentle chime bells (zero external audio dependencies, works 100% offline).
